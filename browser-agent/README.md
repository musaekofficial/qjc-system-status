# 사무실 브라우저 비서

맥미니에 실제 브라우저 창을 띄워 두고, 사장님과 직원 두 명이 채팅으로 시키면 AI(Claude)가 사람처럼 클릭하고 입력해서 일을 대신하는 에이전트입니다. Tailscale 안에서만 열리고 인터넷에는 노출되지 않습니다.

```
[사장님 폰 / 직원 폰 2대]  ← Tailscale 앱
        │  https://맥미니이름.tailnet이름.ts.net  (tailnet 안에서만 열림)
[맥미니]
  ├─ tailscale serve  → 누가 접속했는지 Tailscale 로그인으로 알려 줌
  ├─ 채팅 서버 (127.0.0.1:3080)
  ├─ 에이전트 루프 (Claude API)
  ├─ 사람별 브라우저 창 (Chrome, 로그인·쿠키가 사람마다 따로)
  ├─ 금고 (사이트 비밀번호 암호화 보관, AI는 값을 못 봄)
  └─ SQLite (대화, 승인, 기억, 비용 기록)
```

## 영상의 다섯 가지 결정을 이렇게 구현했어요

| 결정 | 이 프로젝트에서 | 코드 |
|---|---|---|
| ① 셀 | 3명 규모라 셀은 생략했어요. 대신 사람마다 브라우저 프로필, 대화, 개인 기억이 따로 있어요 | `browser.ts`, `memory.ts` |
| ② 비밀은 에이전트 밖에 | 사이트 비밀번호는 맥미니 터미널에서만 금고에 넣어요. AI는 `fill_login`으로 "어느 것을 쓸지"만 고르고, 실제 입력은 코드가 해요. 저장된 주소와 지금 페이지 주소가 다르면 입력하지 않아요. 채팅에 쓴 카드번호, 비밀번호, 주민번호는 저장하기 전에 가려요 | `vault.ts`, `redact.ts` |
| ③ 게시는 코드가 | 버튼 글자(게시, 결제, 전송, 삭제 등), POST 양식 제출, 글 입력칸에서 누르는 Enter는 코드가 위험으로 분류해요. 위험한 동작은 사장님이 [승인]을 누르거나 `승인 3`처럼 정해진 말로 답해야만 실행돼요. 승인 요청에는 번호와 만료 시간(15분)이 있고, 직원은 승인할 수 없어요. 버튼처럼 안 보이는 요소가 몰래 POST로 제출하는 것도 브라우저 단에서 막아요 | `browser.ts`, `approvals.ts`, `agent.ts` |
| ④ 기억은 사람 말로만 | 웹을 읽은 작업에서는 기억을 바꿀 수 없어요. 기억마다 근거가 된 메시지 id가 붙어요. 회사 공용 기억은 사장님만 바꿀 수 있고, 개수 상한은 40개예요 | `memory.ts` |
| ⑤ 상한 | 작업 하나 $3, 한 사람 하루 $15, 전체 하루 $30 (`.env`에서 바꿀 수 있어요). 전체 상한을 넘으면 새 요청을 받지 않아요 | `agent.ts` |

영상에서 말한 함정 다섯 개도 막았어요.

| 함정 | 막는 방법 |
|---|---|
| 순서가 뒤집힘 | 화면이 메시지마다 순번을 붙여요. 서버는 1.2초 모았다가 순번대로 한 작업으로 묶어요 |
| 같은 메시지가 두 번 옴 | 메시지 id가 같으면 한 번만 처리해요 (네트워크가 끊겨 다시 보내도 안전) |
| 조용히 멈춤 | 작업마다 20분 제한이 있어요(승인 대기 시간은 빼고). 서버가 재시작되면 중단된 작업을 알려 줘요 |
| 끝나지 않음 | 최대 60단계까지만 해요. 같은 동작을 3번 반복하면 경고하고, 5번이면 멈춰요 |
| 실패를 무시함 | 모든 오류를 채팅에 알림으로 남겨요 |

## 맥미니 설치

### 1. 준비물
- **Node.js 22.18 이상:** `brew install node`
- **Google Chrome:** 에이전트가 이 크롬을 씁니다.
- **Tailscale:** 맥미니와 세 사람 폰에 설치하고, 같은 tailnet에 로그인해 둡니다.
- **Anthropic API 키:** https://platform.claude.com 에서 발급합니다.
- **맥미니 설정:**
  - 시스템 설정 → 에너지에서 "잠자기 방지"를 켭니다.
  - 사용자 및 그룹에서 자동 로그인을 켭니다. 브라우저 창을 띄우려면 로그인된 상태여야 해요.

### 2. 설치
```bash
git clone <이 저장소> && cd <저장소>/browser-agent
npm install
cp .env.example .env            # ANTHROPIC_API_KEY 입력
cp users.example.json users.json
```

`users.json`에 세 사람의 **Tailscale 로그인**(Tailscale 관리 화면의 Users에 나오는 이메일)을 적습니다.
```json
{
  "boss@gmail.com":   { "name": "사장님", "role": "owner" },
  "staff1@gmail.com": { "name": "민수",   "role": "staff" },
  "staff2@gmail.com": { "name": "지영",   "role": "staff" }
}
```

### 3. 사이트 로그인 정보를 금고에 넣기
맥미니 터미널에서만 넣습니다. 채팅으로는 절대 받지 않아요.
```bash
npm run vault -- add --label "네이버 회사 계정" --origin https://nid.naver.com --user 회사아이디
# 비밀번호를 물어보면 입력 (화면에 안 보임)
npm run vault -- list
npm run vault -- remove cred_ab12cd
```
- **`--origin`:** 로그인 페이지 주소입니다. 이 주소에서만 입력돼요.
- **`--scope`:** 기본값은 `shared`(모두 사용)이고, 특정 사람 로그인을 적으면 그 사람만 씁니다.
- **마스터 키:** `~/.browser-agent/master.key`에 생깁니다. 이 파일을 잃어버리면 금고를 열 수 없으니 따로 백업해 두세요.

처음 한 번은 사이트에 직접 로그인해 두는 방법도 있어요. 에이전트 브라우저 창에서 직접 로그인하면 쿠키가 프로필에 남습니다. 휴대폰 인증이 필요한 사이트는 이 방법이 편해요.

### 4. 실행하고 tailnet에 열기
```bash
npm start                       # 127.0.0.1:3080
tailscale serve --bg 3080       # https://맥미니이름.tailnet이름.ts.net 으로 tailnet 안에만 공개
```
폰에서 Tailscale을 켜고 그 주소를 열면 됩니다. 홈 화면에 추가해 두면 앱처럼 쓸 수 있어요.

> `tailscale funnel`은 인터넷 전체에 공개하는 명령이니 쓰지 마세요. 꼭 `serve`만 씁니다.

### 5. 자동 시작
```bash
sed -e "s|PROJECT_DIR|$PWD|g" -e "s|NODE_PATH|$(which node)|g" deploy/com.office.browser-agent.plist \
  > ~/Library/LaunchAgents/com.office.browser-agent.plist
launchctl load ~/Library/LaunchAgents/com.office.browser-agent.plist
```

### 6. Tailscale 접근 규칙 (권장)
Tailscale 관리 화면 → Access controls에서 맥미니에는 이 세 사람만, 443 포트로만 접속할 수 있게 해 두세요. 규칙을 바꾼 뒤에는 세 사람 폰에서 채팅이 열리는지 확인하세요. 서버는 `users.json`에 없는 로그인을 어차피 막지만, 이렇게 해 두면 한 겹 더 막을 수 있어요.

## 쓰는 법
- **일 시키기:** 채팅에 할 일을 적습니다. 예: "쿠팡 윙에서 오늘 들어온 주문 목록 정리해 줘"
- **승인:** 게시, 결제, 전송처럼 되돌릴 수 없는 동작은 사장님 화면에 승인 카드가 뜹니다. 카드에는 그 순간의 브라우저 화면이 함께 나와요. [승인]을 누르거나 `승인 3`이라고 보내면 실행되고, `거절 3`이라고 보내면 취소됩니다.
- **멈추기:** "멈춰"라고 보내거나 [멈춤] 버튼을 누릅니다.
- **기억시키기:** "앞으로 블로그 글은 반말로 써" 같은 말은 기억으로 저장됩니다. 사장님이 "회사 공용으로 기억해"라고 하면 회사 공용 기억이 됩니다.
- **화면 보기:** [화면] 버튼을 누르면 에이전트 브라우저의 마지막 화면이 보입니다. 맥미니 화면 공유로 실시간으로 볼 수도 있어요.

## 설정 (.env)
| 변수 | 기본값 | 설명 |
|---|---|---|
| `MODEL` | `claude-opus-5-5` | 쓸 모델. 예: `claude-fable-5-2`(더 똑똑하고 2배 비쌈), `claude-sonnet-5-5`(절반 가격) |
| `EFFORT` | `high` | 생각 깊이: `low` / `medium` / `high` / `xhigh` / `max` |
| `BROWSER_CHANNEL` | (Chromium) | `chrome`이면 설치된 구글 크롬 사용 |
| `HEADLESS` | `0` | `1`이면 창 없이 실행 |
| `LIMIT_TASK_USD` / `LIMIT_USER_DAY_USD` / `LIMIT_TOTAL_DAY_USD` | 3 / 15 / 30 | 비용 상한 (달러) |
| `MAX_STEPS` / `TASK_TIMEOUT_MIN` | 60 / 20 | 작업당 최대 단계, 최대 시간(분) |
| `APPROVAL_TTL_MIN` | 15 | 승인 요청 유효 시간(분) |

AI 호출에는 이런 기능이 켜져 있어요.
- **거절 시 다른 모델로 재시도:** 안전 필터가 요청을 거절하면 서버가 다른 모델로 한 번 더 시도해요(`fallbacks: "default"`).
- **오래된 화면 기록 정리:** 지난 스냅샷과 스크린샷은 서버 쪽 정리 기능(context editing)으로 지워서 비용을 줄여요.
- **진행 메모 표시:** 도구를 쓰는 사이에 AI가 남기는 짧은 진행 메모를 화면에 보여 줘요.

## 알아 두실 한계
- **위험 판단은 버튼 글자와 양식 종류로 해요.** 웹페이지 안에서 몰래 보내는 요청(fetch/XHR)까지는 못 막습니다. 결제처럼 중요한 사이트는 결제 비밀번호나 휴대폰 인증 같은 사이트 자체 확인 절차를 켜 두세요.
- **웹페이지에 숨은 지시문:** AI가 읽은 글 때문에 엉뚱한 주소를 열 수는 있어요. 다만 비밀번호와 카드번호는 AI 대화에 들어가지 않아서 새어 나갈 수 없어요.
- **화면 구조의 한계:** iframe이나 shadow DOM 안의 버튼은 목록에 안 나올 수 있어요. 그럴 때는 스크린샷을 보고 판단해요.
- **사람 확인 절차:** 캡차와 휴대폰 인증은 사람이 직접 해야 해요. AI는 그런 화면을 만나면 멈추고 알려 줍니다.
